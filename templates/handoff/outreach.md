## Task: write outreach that gets a real conversation

Target contact type: **{{CONTACT_TYPE}}** (recruiter, hiring manager or peer).
If a profile or posting is in DATA, tailor to it; if not, write a version with
clearly marked `[placeholders]`.

Produce:

1. **One connection message of at most {{LIMIT}} characters** (count them). It must be
   short and genuine: no fluff, no begging, no "Hi sir", no request for a referral or
   a job. Give one concrete reason this person specifically. Mention only things in
   FACTS.
2. **Three follow-up messages** to send if there is no reply, spaced days apart. Each
   must add value (a relevant observation, a useful link the candidate could share,
   a specific question about the work) instead of asking for a referral.
3. One line per message on why it should work.

Never claim the candidate wrote, built or owns something unless FACTS says so.
